USA brick wall construction uses standard measurements to determine material needs, typically requiring 7 bricks per square foot for a single-wythe wall (including standard 3/8-inch mortar joints). Standard US Modular bricks are $7\frac{5}{8}\text{''}$ x $2\frac{1}{4}\text{''}$ x $3\frac{5}{8}\text{''}$ (actual size), but are calculated using a nominal size of 8'' x 2\frac{2}{3}\text{''}$ to account for mortar. [1, 2, 3, 4, 5]  
Standard US Brick Calculations 

• Brick Size (Nominal): Most common is the modular brick, treated as 8" long x 2-2/3" high, resulting in 6.75 to 7 bricks per square foot. 
• Mortar Joint: Standard width is 3/8-inch. 
• Wall Coverage: Single-skin/wythe walls (4 inches thick) require ~7 bricks per sq ft; double-skin/wythe walls require ~14 bricks per sq ft. 
• Waste Factor: Always add 10% to the final, calculated brick total to account for breakage. [1, 4, 6, 7, 8]  

Calculation Steps (Area Method) 

1. Calculate Wall Area: $\text{Length} \times \text{Height (in feet)}$. 
2. Deduct Openings: Subtract area of windows and doors. 
3. Multiply by Coverage: $\text{Total Net Sq Ft} \times 7$. 
4. Add Waste: $\text{Total Bricks} \times 1.10$. [1, 6, 9, 10, 11]  

Standard Brick Types (USA) 

• Modular: 7 5/8" x 2 1/4" x 3 5/8" (Actual). 
• King Size: 9 5/8" x 2 5/8" x 3 5/8" (Approx). 
• Utility: 11 5/8" x 2 5/8" x 3 5/8" (Approx). [2, 4, 6]  

Using ASTM standards ensures bricks meet size tolerances. [12]
